# Contributing / Contribuire

**English:** Thank you for helping improve WG Deck. Please discuss major features in an issue before starting work. Fork the project, use a focused `work/*` branch and send a pull request against `main` with tests and a short explanation of the security impact. Run `bash scripts/local_gate.sh` and keep screenshots synthetic (`bash scripts/capture_demo_suite.sh`). Never attach WireGuard `.conf` files, private keys, PSKs, root-only backups or raw sensitive network logs. Privileged code changes need specific security review and a disposable lab test. Contributors agree to provide contributions under GPL-3.0-or-later.

**Italiano:** Grazie per contribuire a WG Deck. Apri una issue per proposte importanti, utilizza un branch `work/*` nella tua fork e invia una pull request verso `main` con test e indicazione degli impatti di sicurezza. Prima esegui `bash scripts/local_gate.sh`; per immagini usa solo `bash scripts/capture_demo_suite.sh`. Non allegare configurazioni VPN, chiavi private, PSK, backup root-only o log sensibili. Le modifiche agli helper privilegiati richiedono review di sicurezza e verifica su profilo sacrificabile. I contributi sono rilasciati sotto GPL-3.0-or-later.
